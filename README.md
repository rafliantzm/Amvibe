# Amvibe

Amvibe adalah platform orchestration untuk product development yang membantu mengubah ide menjadi PRD, rencana implementasi, dan coding prompts yang siap dieksekusi.

Repository ini berisi beberapa bagian utama:

- `frontend/` untuk aplikasi web utama berbasis Next.js
- `supabase/` untuk migration dan kebutuhan database
- `docs/` untuk dokumentasi dan aset pendukung
- `tools/` untuk utilitas internal tambahan

## Menjalankan Project

Masuk ke folder frontend lalu jalankan development server:

```bash
cd frontend
npm install
npm run dev
```

Lalu buka `http://localhost:3000`.
